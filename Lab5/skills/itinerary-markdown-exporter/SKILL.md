# 旅遊行程 Markdown 匯出

## 適用時機

只有使用者明確要求把這輪或先前對話中已完成的旅遊行程存成檔案、匯出，或整理成
Markdown 文件時使用。一般問答、第一次產生行程或只要求修改內容時不要套用。

## 匯出規則

1. 只能使用對話中最近一次已完成的行程，不得重新執行景點規劃、呼叫住宿規劃 Agent 或
   天氣與交通資訊 Agent，也不得使用任何搜尋、住宿、天氣或匯率工具，且不得加入原行程沒有的新事實。
2. 如果對話中沒有可匯出的完成版行程，停止操作並告知使用者先完成一份行程，不得憑空
   產生內容或建立空白檔案。
3. 使用者有指定檔名時採用指定名稱；未指定時以「目的地-旅遊行程」命名。移除路徑符號，
   並確認檔名以 `.md` 結尾。
4. Markdown 文件依序包含：
   - 標題
   - 行程摘要
   - 使用者偏好
   - 每日行程
   - 交通與預算
   - 注意事項與來源
   Markdown 格式只用在準備交給 `File Writer Tool` 的檔案內容；Agent 之間的交接內容
   與寫檔完成後對使用者的終端回覆仍使用純文字。
5. 使用 `File Writer Tool` 寫檔，`directory` 固定傳入 `.`，`overwrite` 固定為 `false`；
   工具已將寫入範圍限制在專案的 `exports/` 資料夾。
6. 若工具回報同名檔案已存在，不得覆寫；在檔名後加上 `-2` 後重試一次。第二次仍失敗
   就停止並回報錯誤，不得無限重試。
7. 寫檔成功後立即停止，最終回答只能包含 `exports/` 開頭的實際相對路徑，例如
   `exports/大阪-旅遊行程.md`。不得回傳 Markdown 內文、檔名說明、成功訊息，也不得
   繼續搜尋、重新規劃或再次寫檔。
